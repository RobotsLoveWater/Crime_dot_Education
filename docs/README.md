# Project documentation

This directory holds the durable project documentation that supports the Minnesota Sentencing Explorer.

- [Architecture](architecture/) explains the application, its data model, major technical decisions,
  and the current [repository layout](architecture/repository-layout.md).
- [Design](design/) contains the product and interface design authorities.
- [Research](research/) contains the public project manuscript and retained historical versions.
- [Archived implementation plans](archive/plans/) preserve completed, phase-by-phase build plans for project history.

The repository root intentionally retains only the project entry points: [README.md](../README.md),
[ROADMAP.md](../ROADMAP.md), [AGENTS.md](../AGENTS.md), and [LICENSE](../LICENSE).
